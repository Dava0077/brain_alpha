# 🧠 Simon Says Game — Technical Documentation

## Overview

The **Simon Says Game** is a **sequential memory challenge** where players must repeat a series of color cues in the correct order. Each round, the game appends a new color to the sequence, testing the player’s **working memory**, **attention**, and **pattern retention**.

This module is implemented using **Jetpack Compose Multiplatform**, with clearly separated **Model**, **Controller**, and **View** layers.

---

## Architecture Summary

### 1. `simonModel.kt`
Contains all the game’s **core logic and state**.

- `difficulty`: Current difficulty level.
- `availableColors`: Fixed list of 4 color names.
- `machineSequence`: The sequence generated by the game.
- `playerSequence`: The player's current input.
- `state`: Enum `GameState` — `START`, `MACHINE`, `PLAYER`.
- `score`: Number of correct sequences completed.

#### Key Functions

| Function | Purpose |
|---------|---------|
| `startGame()` | Resets all data and begins a new round. |
| `addRandomColor()` | Adds a random color to the sequence. |
| `addPlayerColor(color)` | Adds the player’s input to their sequence. |
| `validatePlayerInput()` | Compares latest input to corresponding machine value. |
| `isPlayerSequenceComplete()` | Checks if the player's sequence matches full length. |
| `getFinalScore()` | Calculates score × difficulty multiplier. |
| `getDelayBetweenColors()` | Determines time between colors by difficulty. |
| `getAnimationSpeed()` | Speed of color display animation. |
| `resetGame()` | Full game state reset. |

---

### 2. `simonController.kt`
Acts as the intermediary between `simonModel.kt` and the UI.

#### Responsibilities

- Tracks `uiState`: current message, turn status, score, and color sequence.
- Starts the game (`onStartPressed()`).
- Processes player input (`onColorPressed()`).
- Triggers model functions: scoring, validation, round transitions.
- Handles difficulty selection and instruction display toggle.
- Exposes game-over state for result handling.

> The controller ensures that the view layer reacts only to clean, observable state updates.

---

### 3. `simonScreen.kt`
The main game screen built with Compose.

- Renders:
  - Top bar (profile, score, settings)
  - Difficulty selector (if not in-game)
  - Animated color display box
  - 4 color buttons (Red, Green, Blue, Yellow)
  - Score and game messages
  - "Play / Restart" button
- Reacts to state changes like `isUserTurn`, `gameOver`, `sequence`.

### 4. `InstructionsSimon.kt`
- Renders instructional content.
- Stylized with `AnnotatedString` for bold text.
- Contains a single CTA to begin the game.
