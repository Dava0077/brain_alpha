# 🧠 Simon Says Game - Player Guide

## 🎯 Objective

The **Simon Says** game is a classic memory challenge that tests your **attention**, **recall**, and **reaction time**.

Your goal is to **memorize and repeat the exact sequence of colors** shown by the system.

Each round adds a new color to the sequence. Repeat it perfectly to move forward!

---

## 🕹️ How to Play

1. Watch the **sequence of flashing colors** shown on the screen.
2. When it's your turn, **repeat the sequence** by tapping the color buttons in the same order.
3. If you get it right, the next round adds one more color.
4. If you tap the wrong color — the game ends.

> 🎯 Accuracy and focus are key!

---

## ⏱️ Speed & Difficulty Levels

The game becomes faster with higher difficulty levels.  
Each level affects the **speed of the light sequence** and **animation time**:

| Difficulty | Delay Between Colors | Animation Speed |
|------------|----------------------|------------------|
| 🟢 Easy     | 1500 ms              | 500 ms           |
| 🔵 Medium   | 800 ms               | 200 ms           |
| 🔴 Hard     | 300 ms               | 50 ms            |

You can select difficulty before starting.  
Difficulty adjusts automatically based on your total score if you're logged in.

---

## 🧠 Scoring System

Each round you complete gives you **+1 point**.  
Your final score is **multiplied** based on difficulty:

| Difficulty | Multiplier |
|------------|------------|
| 🟢 Easy     | ×1         |
| 🔵 Medium   | ×2         |
| 🔴 Hard     | ×3         |

For example:  
- 7 rounds completed on 🔵 Medium → **14 Neurons**  
- 10 rounds completed on 🔴 Hard → **30 Neurons**

## 🔓 Unlocking Difficulties

Earn neurons by playing and scoring higher.

## 🎮 Interface Overview

- 🎛️ **Top Bar**: Profile, settings, and neuron count.
- 🎨 **Center Box**: Displays the current flashing color.
- 🟥🟩🟦🟨 **Color Buttons**: Tap in the correct sequence.
- 🧾 **Status**: Shows current score and game messages.

### Controls:

- 📖 **Instructions**: Opens this help guide.
- 🚀 **Play / Restart**: Starts or restarts the game.
- 🔙 **Back**: Returns to main menu.

---

## 💡 Pro Tips

- Play in a **quiet environment** to avoid distractions.
- Repeat the sequence **in your head** as it's being shown.
- Tap **slow and steady** — don’t rush.
- The sequence always starts from the **beginning** — memorize the full chain.
