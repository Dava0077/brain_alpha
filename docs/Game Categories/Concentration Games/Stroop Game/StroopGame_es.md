# 🧠 Guía del Juego Stroop Test

## 🎯 Objetivo

El **Test de Stroop** es un ejercicio clásico de psicología diseñado para entrenar tu **atención** y **agilidad mental**.

Tu objetivo es **seleccionar el color en el que está escrita la palabra**, _no la palabra en sí_.

Por ejemplo:

- La palabra es `AZUL`, pero está pintada en **rojo**.
- Debes seleccionar: **Rojo** ✅

---

## 🕹️ Cómo Jugar

1. Aparecerá una palabra que representa un color (como `"VERDE"`).
2. El **color del texto** puede ser diferente a su **significado**.
3. Tu tarea:
   > **Toca el color que ves, no el que lees.**

4. Aparecerán varias opciones de colores. Elige la que coincida con el color visible del texto.

---

## ⏱️ Tiempo y Dificultades

Dispones de un **tiempo limitado** para acumular la mayor cantidad de puntos posible.

Cada dificultad tiene un límite de tiempo diferente:

| Dificultad | Tiempo disponible |
|------------|------------------|
| 🟢 Fácil    | 45 segundos       |
| 🔵 Medio    | 30 segundos       |
| 🔴 Difícil  | 15 segundos       |

Puedes ver el tiempo restante en una barra de progreso y contador en pantalla.

---

## 🧠 Sistema de Puntos

- ✅ **+100 puntos** por cada respuesta correcta.
- ❌ **–20 puntos** por cada error.
- El juego termina cuando se agota el tiempo.

Los puntos se acumulan como **🧠 Neuronas** y desbloquean nuevas funciones.

---

## 🔓 Desbloqueo de Dificultades

| Requisito de desbloqueo | Dificultad |
|--------------------------|------------|
| Ninguno                  | 🟢 Fácil    |
| 50 Neuronas              | 🔵 Medio    |
| 150 Neuronas             | 🔴 Difícil  |

Gana neuronas jugando partidas y mejorando tu puntuación.
