## 🟦 Tables and Relationships
The **main tables** in the BrainAlpha database:
- `users`: Stores user accounts.
- `games`: Stores game metadata.
- `user_progress`: Tracks user progress in games.
- `game_sessions`: Records each game session.
- `achievements`: Stores available achievements.
- `user_achievements`: Links users to achievements.
- `leaderboard`: Stores leaderboard rankings.
- `settings`: Stores user preferences.
